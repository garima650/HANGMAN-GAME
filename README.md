# HANGMAN GAME
A classic word-guessing game played right in your command line. Guess the hidden word letter by letter before you run out of attempts and complete the ASCII-art gallows.

How It Works

• Secret Word: The program picks a random word and shows its length as blank lines or underscores.
• Letter Input: You type a single letter on each turn to test if it belongs in the word.
• ASCII Art: Each wrong guess draws another part of the stick figure on the terminal screen.
